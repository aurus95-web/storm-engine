# «Корсары 2» на iPad и iPhone

Порт движка Storm Engine (форк [PiratesAhoy](https://github.com/PiratesAhoy/storm-engine)) на iPadOS / iOS
для оригинальной игры **«Корсары 2» / Pirates of the Caribbean** (Акелла, 2003).

В [релизах](https://github.com/aurus95-web/storm-engine/releases) лежит IPA — **только движок**, без игры.
Файлы игры защищены авторским правом и не распространяются: нужна своя копия игры для ПК.

Что сделано в порте:
- графика: Direct3D 9 игры → DXVK (Vulkan) → MoltenVK (Metal);
- звук: miniaudio;
- сенсорное управление:
  - экранные кнопки и стики;
  - касания в меню;
  - меню команд пальцем;
- геймпад: Xbox, PlayStation, MFi;
- клавиатура и мышь или трекпад iPad.

Проверено на двух устройствах:
- iPad Pro 12.9" (M1), iPadOS 15.3.1;
- iPhone 14 Pro Max, iOS 26.

Минимальная версия — iOS / iPadOS 15. На других устройствах не проверялось. Нужно устройство с 4+ ГБ памяти
(A12 и новее).

## 1. Что понадобится

- **Игра «Корсары 2» / «Пираты Карибского моря» для ПК.** Это ваша копия: диск или установленная на Windows игра.
  Нужна папка игры, в которой лежат `PROGRAM`, `RESOURCE`, `MODULES`. Проверялась русская версия.
- **Beyond New Horizons** — бесплатный мод той же игры: <https://cmdrhammie.itch.io/beyond-new-horizons>.
  Из него берутся файлы, которых нет в оригинале, но которые нужны этому движку: волны моря, частицы, несколько
  текстур моря и карты. Скачайте и распакуйте архив для Windows.
- **Компьютер с Python 3** (macOS, Windows или Linux) — для подготовки файлов игры.
- По желанию — **ffmpeg**, чтобы перекодировать видеоролики (без этого ролики не показываются).

## 2. Подготовка файлов игры

Скопируйте папку игры (скрипт меняет её на месте) и выполните из папки этого репозитория:

```bash
python3 tools/potc/prepare_potc.py <папка игры> <папка Beyond New Horizons> --screen=1366x1024 --icons
```

Скрипт:
- перекодирует тексты скриптов и интерфейса из Windows-1251 в UTF-8;
- скопирует из Beyond New Horizons только недостающие файлы;
- распакует текстуры неба;
- запишет `engine.ini` для iPad (старый сохранится как `engine.ini.orig`);
- с ключом `--icons` нарисует картинки экранных кнопок.

`--screen` — разрешение, в котором игра рисует кадр; на экран оно растягивается само. Для iPad 12.9" подходит
`1366x1024` — это ровно половина экрана. Для iPhone с «чёлкой» лучше взять размер безопасной зоны в точках,
например `1222x645` для iPhone 14 Pro Max. Чем больше разрешение, тем сильнее нагрев.

Видеоролики (нужен ffmpeg; на macOS — `brew install ffmpeg`):

```bash
tools/video/convert-videos.sh <папка игры>
```

Файлы `.wmv` на устройство копировать не нужно, достаточно получившихся `.mp4`.

## 3. Установка IPA

IPA подписан ad-hoc. Подойдёт любой из способов:

- **Sideloadly** (<https://sideloadly.io>, Windows и macOS) или **AltStore** — с вашим Apple ID.
  - С бесплатным Apple ID подпись действует 7 дней, потом приложение нужно переподписать.
  - Sideloadly сам поменяет идентификатор приложения, если это потребуется.
- **TrollStore** (iOS 14.0–16.6.1 и 17.0) — ставится навсегда.
- **Джейлбрейк + AppSync Unified** — `ideviceinstaller install StormEngine.ipa` или через Filza.

Приложение называется **Storm Engine**.

## 4. Копирование игры на устройство

Приложение один раз запустите и закройте: так появится его папка. Затем скопируйте **содержимое**
подготовленной папки игры (`engine.ini`, `PROGRAM`, `RESOURCE`, `MODULES` и остальное) в папку приложения.

Способы копирования:
- **macOS:** Finder → устройство в боковой панели → вкладка «Файлы» → Storm Engine → перетащить файлы.
- **Windows:** iTunes или «Устройства Apple» → «Общие файлы» → Storm Engine.
- **На самом устройстве:** приложение «Файлы» → «На iPad» / «На iPhone» → Storm Engine.

Подсказки:
- Игра занимает 2–3 ГБ. Папку `RESOURCE/VIDEOS` без `.wmv` копировать быстрее.
- Сохранения и настройки (`SAVE`, `options`) лежат там же. При обновлении приложения они не пропадают.

Если в папке приложения нет `engine.ini` и `PROGRAM`, при запуске движок покажет ошибку.

## 5. Управление

- **Сенсорное:**
  - кнопки справа, набор зависит от режима (суша, бой, море, палуба, карта);
  - стик ходьбы — в любом месте левой половины экрана;
  - камера — палец, отведённый в сторону;
  - щипок — приближение;
  - тап по меню команд выбирает команду.
- **Геймпад:** раскладка как у Xbox-версии игры. Пока вы играете геймпадом, экранные кнопки скрыты.
- **Клавиатура и мышь:** как на ПК.

Настройки порта задаются в `engine.ini`, в процентах от значения по умолчанию:

```ini
[touch]
button_scale = 100       ; размер экранных кнопок и значков
stick_scale = 100        ; размер стиков
camera_speed = 100       ; скорость камеры от касаний
zoom_speed = 100         ; скорость приближения
pad_camera_speed = 100   ; правый стик геймпада
pad_turn_speed = 100     ; поворот героя левым стиком
dialog_text_scale = 100  ; текст диалогов (на iPhone удобно 150)
sea_ship_speed = 120     ; скорость кораблей в море
sea_ship_turn = 125      ; поворот кораблей в море
map_ship_speed = 120     ; скорость кораблей на карте
map_ship_turn = 125      ; поворот кораблей на карте
```

Кнопки геймпада по режимам переназначаются в разделах `[gamepad_<группа управления>]`, например
`[gamepad_Sailing3Pers]`. Пример строки: `r2 = Ship_Fire`. Значение `-` значит «кнопка не назначена».

Пункты этих настроек в меню игры («Изображение», «Сенсорное управление», «Геймпад») требуют изменённых
скриптов игры. Они не распространяются, потому что это файлы игры. Без них в меню остаются обычные настройки,
а всё перечисленное выше работает через `engine.ini`.

## 6. Если что-то не работает

В папке приложения лежат журналы:
- `system.log` — журнал движка;
- `error.log` — ошибки скриптов;
- `stderr.log` — графика и звук;
- `crash.log` — стек при вылете.

Приложите их к описанию проблемы.

## Сборка из исходников

Описана в [CLAUDE.md](../../CLAUDE.md) («Сборка», п. 4 «iPad»). Кратко:

```bash
cmake --preset ios -B build/ios-ma -DSTORM_IOS_BUNDLE_ID=<ваш.id> \
      -DSTORM_MOLTENVK_PATH=<.../MoltenVK.xcframework/ios-arm64/MoltenVK.framework> \
      -DSTORM_SOUND_MINIAUDIO=ON -DCMAKE_XCODE_ATTRIBUTE_CODE_SIGNING_ALLOWED=NO
cmake --build build/ios-ma --config Release
tools/ios/package-adhoc.sh build/ios-ma/Release/engine.app StormEngine.ipa
```
